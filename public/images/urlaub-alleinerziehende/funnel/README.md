## Hinweise zur Bildgestaltung

- **Seitenverhältnis:** 4:3 oder 16:9 (Karten werden mit `cover` beschnitten)
- **Auflösung:** mind. 800 × 600 px (für Retina: 1600 × 1200 px)
- **Format:** PNG (oder JPG, dann Dateinamen anpassen)
- **Stil:** Emotional, warm, familienfreundlich – passend zum ApeAround/Reisemonkeys-Design
- **Keine Texte** in den Bilddateien selbst – Text wird als HTML über die Karte gelegt
- **Kein Markenlogo** in den Bildern

Sobald die Bilder platziert sind, zeigt der Funnel sie automatisch. Solange eine Datei fehlt, wird das Fallback-Bild aus `/images/funnel/cards/` genutzt.
